## 3. 重点查证：市面 DS18B20 假货问题

**核心来源**
- GitHub 项目（作者 Chris Petrich）：<https://github.com/cpetrich/counterfeit_DS18B20>
- CNX Software 报道（2020-07-13，Jean-Luc Aufranc）：<https://www.cnx-software.com/2020/07/13/fake-ds18b20-temperature-sensors-counterfeit-clones/>
- 渠道侧佐证：Adafruit 商品页明确写 "As of January 2021 – we test that these are genuine Maxim DS18B20's"，并直接链接到该 GitHub 项目的检测脚本：<https://www.adafruit.com/product/381>

### 3.1 调查事实（来自 CNX 对 GitHub 项目的报道）

| 项目 | 内容 |
|---|---|
| 抽样规模 | 2019 年，团队从 **eBay、AliExpress 及 70+ 家网店**买入 **1000 支以上**防水探头或裸片 |
| 结论 | **绝大多数是假货、仿冒品或克隆品** |
| 具体缺陷 | 部分假货**不支持寄生供电**、**噪声高**、**温度偏差超出标称 ±0.5℃ 区间**、**没有 EEPROM**、存在 bug 与未标称的失效率 |
| 丝印鉴别 | 原厂 Maxim 芯片顶部为**激光刻字（lasered）而非印刷**，前两行应为 `DALLAS 18B20`（Dallas Semiconductor 2001 年被 Maxim 收购） |
| **ROM 码鉴别** | 原厂 64 位 ROM 码应符合 **`28-xx-xx-xx-xx-00-00-xx`** 格式；不符合即为克隆 |
| 自动化检测 | `discover_fake_DS18B20.ino`：做安全测试，判断是否偏离原厂行为（**不支持寄生供电模式**）；`classify_fake_DS18B20.ino`：用未公开功能码匹配具体"家族"，**可能永久损坏器件，风险自负** |
| 已知克隆家族 | **UMW / GXCAS 18B20**（基本符合规格）、**7Q-Tek QT18B20**（0℃ 时存在 **-0.5℃ 偏移**）、无品牌件 "Noisy Rubbish with Supercap" 与 "Noisy Rubbish"（后者在大量卖家中流通） |
| 采购建议 | **避开 eBay 与 AliExpress**；直接向 Maxim（现 Analog Devices）或授权分销商（DigiKey、Farnell、Mouser、RS Components）采购 |

### 3.2 关于「读数 85℃」

用户提示中提到的「读数 85℃」**在上面两篇指定来源中没有出现**。85℃ 是 DS18B20 上电复位后温度寄存器的默认值（见器件数据手册），在供电不足 / 寄生供电失败时常见，但**本次未在指定来源中找到对应依据**，故不列为已查证结论。→ 详见第 8 节。

### 3.3 对本项目（鱼塘水温）的直接含义

- 买探头时**优先选明确标注"原装 Maxim/ADI 芯片"并可提供抽检报告的卖家**；淘宝上"进口达拉斯"字样基本无鉴别价值。
- 到货后**至少抽检 1–2 支**：读 64 位 ROM 码，检查是否为 `28-…-00-00-…` 格式；再跑 `discover_fake_DS18B20.ino`。
- 长期泡水场景建议**留 10%–20% 备件**，因为假货的失效率未被标称。

### 5.1 SHT31 能不能长期泡水？—— **不能**

**结论：不适合。水下测温请改用 DS18B20 不锈钢探头或 PT100/PT1000 铠装探头。**

依据：
1. **Sensirion 为 SHT3x 单独提供 IP67 滤膜选件（Membrane Option）**，这本身就说明裸片不具备防水防尘能力，需要额外防护才能接触水和粉尘。
   - Sensirion 官方文档（HT_DS_SHT3x_Membrane.pdf）：<https://sensirion.com/media/documents/9D103E42/67EB901F/HT_DS_SHT3x_Membrane.pdf>
     （**说明**：该直链本次抓取返回 404，标题来自搜索引擎索引，请自行打开确认版本）
   - DigiKey 托管的同名规格书：<https://digikeytest.digikey.cn/zh/htmldatasheets/production/1991133/0/0/1/sht3x-membrane-option-spec>
   - 行业报道（IP67 滤膜保护 SHT3x 免受水与粉尘）：<https://www.electronicspecifier.com/products/sensors/ip67-filter-membrane-protects-sensor-from-water-and-dust/>（本次抓取被 Cloudflare 拦截）
2. **DFRobot 专门为 SHT31 推出"防风雨版"（SEN0385，¥139）**，与普通 SHT31 模块（¥63）并存——若裸片本就能防水，不需要单独做这个型号。<https://www.dfrobot.com.cn/goods-2952.html>
3. **工程原理（非来源引用，属常识性判断）**：SHT3x 是开腔式温湿度传感器，湿敏聚合物必须与空气接触才能测 RH。一旦进水：(a) 湿度读数会长时间钉在 ~100%RH，(b) 长期浸泡会导致封装/焊盘腐蚀失效。
4. 即使加了 IP67 滤膜，**长期浸泡也不是官方推荐用法**（滤膜被水覆盖后湿度测量失去意义）；温度虽仍可测，但同价位下 DS18B20/PT100 更合适、更便宜。

## 6. DS18B20 长线（10 m+）工程要点

**主要技术来源：Analog Devices 应用文档《Guidelines for Reliable Long Line 1-Wire Networks》（即 Maxim AN148）**
<https://www.analog.com/en/resources/technical-articles/guidelines-for-reliable-long-line-1wire-networks.html>
（PDF 版：<https://www.analog.com/media/en/technical-documentation/tech-articles/guidelines-for-reliable-long-line-1wire-networks.pdf>）
辅证：Adafruit DS18B20 商品页技术说明 <https://www.adafruit.com/product/381>

### 6.1 两个核心概念

- **radius（半径）**：主机到最远从机的线长。
- **weight（重量）**：网络中**所有连接线总长**。
- 经验法则：**weight 决定上升沿时间，radius 决定最慢反射的时序**。例如 10m+20m+30m 三支星形网络：radius = 30m，weight = 60m。
- 每支从机也等效贡献 weight：非 iButton 从机 ≈ **0.5 m**，iButton ≈ 1 m；ESD 器件与 PCB 走线同样计入（约 24 pF/m，即 24pF ≈ 0.5m 等效线长）；Cat5e UTP 约 **52 pF/m**。

### 6.2 上拉电阻怎么选

| 场景 | 推荐 | 依据 |
|---|---|---|
| 短线（<1–3m，单支/少量） | **4.7 kΩ**（DQ → VCC） | Adafruit 随每支探头附赠 4.7k 电阻 |
| 中等长度 | 减小到 **2.2 kΩ 甚至 1 kΩ**（提高上升沿速度、增大驱动电流） | AN148 Appendix A 的长线方案用 **1 kΩ** 上拉 |
| 长线 / 重网络 | **纯电阻上拉有硬上限**：AN148 明确指出简单电阻上拉的 weight 上限约 **200 m**；要突破必须用**主动上拉（active pull-up）**，可支持 weight **>500 m** | AN148 |

> ⚠️ 关键点：**4.7 kΩ 不是万能值**。它与线缆电容构成 RC 网络，线越长、电容越大，上升沿越慢；到某个长度数据位在采样时刻还没爬到有效高电平，就会出现"设备随机丢失"。**线越长，上拉电阻应越小**，但也不能小到从机拉不动（DS18B20 低电平灌电流能力有限）。

### 6.3 寄生供电 vs 外部供电——长线必须用外部供电

- **寄生供电（parasitic power）**：DQ 线在空闲时给从机内部电容充电，无需 VCC 线，只需 2 根线。
- AN148 明确警告：**寄生供电在重网络下最危险**。最坏情况是主机连续发送一长串 0 bit，总线长时间处于低电平，从机没有机会充电；一旦内部电压跌破临界值，从机会**复位并发出 presence pulse**，从而污染总线上的其他通信。表现为**数据相关的、间歇性的失败**——"设备时有时无"。
- 因此：**长线（10 m 以上）、多节点、需要高可靠性的场景，一律用外部供电（三线制：VCC / GND / DQ）**。DS18B20 支持 3.0–5.5V 外部供电。
- 只有短线、单节点、且主机能提供强上拉时才考虑寄生供电。

### 6.4 拓扑与分支

- **星形（star）拓扑最不可靠，官方不推荐**，且"不保证性能"。分支交汇点阻抗严重失配，反射会沿整条网络传播。
- **stub（分支）≥3m** 就会造成问题。若必须分支，可在分支点串 **100–150 Ω** 电阻：150Ω 可把失配降低约 20%、把分支反射衰减约 40%，但**噪声容限会下降约 80%**，需谨慎。
- ⚠️ 该串阻方法与 **DS2480B / DS2484** 这类带主动上拉的 1-Wire 主机**不兼容**。
- 推荐拓扑：**线性（linear）**，主机在最一端，探头沿线分布，分支 <3m。

### 6.5 线材与屏蔽（工程建议）

| 项目 | 建议 |
|---|---|
| 线型 | **双绞 + 屏蔽**：DQ 与 GND 绞合成一对（降低环路面积与串扰），屏蔽层**单端接地**（接主机侧 GND），两端接地会形成地环流 |
| 线规 | ≥ **24 AWG**（约 0.5 mm²）多股镀锡铜；避免铝包铜/铁芯线（回路电阻大，寄生供电下压降剧增） |
| 参考 | AN148 的实测基于 **Cat5e 双绞线 + 5V 总线供电**；Cat5e 约 52 pF/m |
| 防水 | 探头与线材连接处必须是一体注塑/双层环氧灌封；现场自己热缩管接长在潮湿环境是主要失效点 |
| 走线 | 远离市电/水泵/变频器动力线；必须交叉时成 90° |

### 6.6 最大总线长度——官方数字与现实

- AN148 给出的可支持上限（**条件是：Cat5e 双绞线 + 5V 总线供电 + 专用 1-Wire 主机**）：
  - 简单电阻上拉：weight 上限约 **200 m**
  - 带压摆率控制的 FET 驱动 + **1 kΩ** 上拉（MCU 端口方案）：radius 与 weight 均可到 **200 m**
  - 带阻抗匹配 + 智能主动上拉的主机（AN244 方案）：radius 与 weight 可达 **500 m**
  - DS2480B + RC 滤波（470pF）：适用于 **10–100 m** 网络
- ⚠️ **重要限定**：以上都是"专用 1-Wire 主机"场景。**用 MCU 引脚直接 bit-bang + 4.7kΩ 上拉时，官方文档并未给出具体米数**——社区经验值（10–30m 内较稳）**属于经验范畴，本次未找到可靠官方来源**，需自行实测验证。
- 另外一个物理限制：信号在电缆中约以 2/3 光速传播，**750 m 电缆往返延迟 7.5 µs**，会直接破坏读时隙——这就是为什么 radius 有硬上限。
- **overdrive 高速模式只适合极短连线，网络中永远不要使用。**

### 6.7 布线自检清单（10m+ 场景）

1. ✅ 三线制外部供电（不要寄生供电）
2. ✅ 上拉电阻按线长实测调整（4.7k → 2.2k → 1k），用示波器看上升沿是否在采样点前到达有效高电平
3. ✅ 线性拓扑，分支 <3m；必须分支时串 100–150Ω
4. ✅ 双绞屏蔽线，屏蔽单端接地，线径 ≥24AWG
5. ✅ 探头接头一体注塑/灌封，不留自制接头
6. ✅ 通信失败时先查**上升沿质量与供电跌落**，再怀疑器件
7. ✅ 建议加**看门狗 + 掉线重扫**逻辑（1-Wire 搜索失败会"丢设备"）
8. ✅ 到货抽检 ROM 码 + 跑 `discover_fake_DS18B20.ino`（见第 3 节）
