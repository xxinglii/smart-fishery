# 合宙 Air780E 硬件手册 V1.0 (PDF)
URL: https://docs.openluat.com/air780e/product/file/Air780E%E7%A1%AC%E4%BB%B6%E6%89%8B%E5%86%8CV1.0.pdf
- 三种功耗模式（3.8V 供电，实网）:
  常规模式: 长连接在线, 最小平均电流 4.7 mA
  低功耗模式: 长连接在线, 最小平均电流 0.47 mA
  PSM+模式: 离线/飞行模式, 平均电流 3 uA
- 测试环境: 3.8V, 移动 B3, RSRP -88, DRX 2.56s, 心跳 5 分钟, 心跳数据 100Byte, TCP
- 低功耗模式 DRX 1.28s -> 0.6mA ; DRX 0.64s -> 0.95mA
- 常规模式 DRX 1.28s -> 4.8mA ; DRX 0.64s -> 4.9mA
- 唤醒能力: 常规/低功耗 支持服务器4G唤醒(1秒内); PSM+ 不支持服务器4G唤醒
- 串口唤醒: 低功耗/PSM+ 唤醒时波特率需先设 9600bps
- 上行发送: 常规/低功耗 1秒内响应; PSM+ 1.5秒内响应
- PSM+ 唤醒后程序从初始状态运行(数据丢失)
- 备注: 低功耗表现最好的型号是 Air780EPS
- 供电范围 3.3~4.3V (可直接锂电供电)

# 合宙 Air780EHV 系列低功耗文档（含 Air9000P 实测）
URL: https://docs.openluat.com/air780ehv/luatos/app/lowpower/sleep/
- 三模式典型功耗: 常规 7~8mA / 低功耗 1.5~2mA / PSM+ 3~12uA  (Air780EXX 系列)
- 实测(3.8V 供电):
  [8.1 常规模式 TCP 长连接] 6分钟总平均 7.4640mA; 常规待机 30.8677mA; 单次发数据 13.4034mA
  [8.2 常规<->低功耗切换] 有卡: 开机->低功耗前 14.0918mA; 低功耗段 1.1126mA;
       切回常规 5.8411mA; 低功耗待机 838.6926uA ; 总平均 2.2308mA
  [8.3 低功耗模式简单项目] 有卡待机 1.0155mA (总 1.4426mA);
       飞行模式待机 62.7591uA (总 151.3722uA); 不插卡待机 62.4159uA (总 136.8772uA)
  [8.4 低功耗 TCP 长连接] 总平均 1.4988mA; 低功耗待机 934.1232uA
  [8.5 低功耗 MQTT 长连接] 总平均 1.7439mA; 低功耗待机 982.1323uA
  [8.6 低功耗串口拍照] 总 384.9393uA; 待机 47.9711uA
  [8.7 PSM+ 简单项目] 有卡 总 80.8697uA / PSM+待机 3.0392uA ; 无卡 总 79.2209uA / 3.0308uA
  [8.8 PSM+ TCP 短连接] (开机->发1条->断连->PSM+ , 1小时唤醒) 5分钟总平均 261.7639uA;
       PSM+待机 3.0969uA; 开机到发完进入PSM+之前 26.9441mA
  [8.9 PSM+ MQTT 短连接] 5分钟总平均 297.1059uA; PSM+待机 3.0969uA;
       开机连接MQTT并发一条温湿度数据期间 30.2442mA
- 附加功耗: 含 GNSS+Gsensor 的型号(GGG/EGP) 额外 ~30uA; 含 Audio Codec 额外 ~45uA
- 注意: 低功耗模式下与基站的 3GPP 保活交互无法省略, 否则掉网
