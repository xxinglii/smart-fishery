1 Introduction 
 
This document mainly introduces the low power mode of Quectel EC200U series, EG91xU family and 
EG915G-EU modules in LTE network. It includes the introduction of related AT command, the data 
comparison of average current consumption tests in different sleep modes in application scenarios as 
well as precautions. 
 
Low power mode refers to the module’s sleeping in low power mode, including normal sleep mode, 
enhanced sleep mode and PSM. 
 
The module enters normal sleep mode (controlled by AT+QSCLK, see Chapter 2.3.1 for details) by 
related pins, or after data interaction finished, then, the overall average current consumption is reduced. 
 
Enhanced sleep mode refers to the fast sleep after the module sends data. The difference between the 
enhanced sleep mode and the normal sleep mode is mainly demonstrated in the scenario where data is 
sent and received at intervals, after the data is sent and received, the module in enhanced sleep mode 
enters the sleep state faster than the module in normal sleep mode, thereby reducing the overall average 
current consumption. 
 
PSM is an ultra low power sleep mode, different from normal sleep mode in that the module in PSM 
consumes less power, which is equivalent to the module has been shut down, and only the default bearer 
is retained for fast camping the network after booting up.  
 
 
The module can enter PSM when it is in normal sleep mode or enhanced sleep mode. When PSM is 
enabled, if not configured to enter enhanced sleep mode, the module will be in normal sleep mode 
before entering PSM.

There is a total of 4 stages in which the module enters PSM from enhanced sleep mode: initiation,

After PSM is enabled, the module reports the values of T3412 timer and T3324 timer as a reference. If the 
operator supports PSM, the network determines whether to uses the reported value to issue to the 
module. The module cannot predict network behavior. If the difference between the T3412 value and the 
T3324 value issued by the network is less than 5 minutes, the module does not enter PSM. In other words, 
although the difference between the T3412 value and the T3324 value reported by the module is higher 
than 5 minutes, and the difference between the T3412 value and the T3324 value issued by the network 
is less than 5 minutes, the module will not enter PSM.
