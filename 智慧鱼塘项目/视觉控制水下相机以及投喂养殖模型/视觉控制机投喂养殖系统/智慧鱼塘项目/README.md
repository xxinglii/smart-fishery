# 🐟 2026 鱼塘 · 项目总览（README）

> **目标**：把鱼塘现有的「摄像头 + 脚本」链路，升级为**基于传感器与投喂模型的自动投喂能力**。
> **现场**：食用鱼养殖，单塘 5–20 亩（3,300–13,300 m²），水深 1.5–2.5 m，户外，**塘边有市电、无宽带**。
> **一句话结论**：**用 ESP32 / 树莓派做「传感 + 决策 + 告警」靠谱；用相机（在任何算力上）做「数鱼」不靠谱。
> 而好消息是——**不需要数清鱼，也能把喂料这件事做好。**

**模型要点**：`W_day = B × r(T, w̄) × f_env / 100`，B = N × w̄ / 1000；投喂率表取 T/SCFA 0011—2023（黄河鲤），温度 × 规格双线性插值、越界钳制不外推；
环境修正 `f_env = f_DO × f_水温 × f_天气`（乘性，溶氧 <3 或 ≥33℃ → 停喂告警）；安全钳制 ≤4.7% 体重/天。
**输出永远是区间**：`[0.7W, 1.3W]`，宁可按下限执行——过量的代价远大于不足。
**绝不**根据累计投料量反推生物量（正反馈发散，见 D2）。

### 6. `水下相机与污损调研/` — 为什么不做水下

**否决证据**：USGS TM1-D3 官方——营养富集温水体「**可能需要每三天维护一次**」；PLOS ONE 2022 实测 1–2 个月内识别即不可行，**防污漆无效**；亚克力窗每 3–4 天需清洗（2003 年某系统误分类中 **24% 来自维护不良**）。
含 `_biofouling_refs/`（5 篇 PDF：Fischer 2020、USGS、Robinson 等）与浊度—可见距离—后向散射的文献调研。
