# 水下成像：浊度（NTU）↔ 可见距离的定量关系，及后向散射的影响

> 可信度：**A** = 同行评议论文 / 政府·标准文件；**B** = 预印本 / 厂商 / 媒体；**C** = 博客·论坛。

## 结论速览

1. **没有检索到"相机可见距离(cm) = f(NTU)"的同行评议直接关系式。** 最接近的 A 级定量锚点有三类：① USGS 用 25 组实测数据拟合的 **Secchi 深度–浊度幂律**；② 鱼类**对比度检测阈值**实验（NTU 达到多少时视觉任务失败）；③ 按**浊度/退化等级分组**的目标检测 AP 数据。
2. 浊度与可见距离**不是线性关系**：USGS 实测为负幂律，`SDD(ft) = 11.123 × Turbidity(FNU)^(-0.637)`，换算为公制 `SDD(m) = 3.390 × NTU^(-0.637)`（[USGS](https://or.water.usgs.gov/will_morrison/secchi_depth_model.html)，A）。
3. **未找到可靠来源给出普适的 NTU → 光束衰减系数 c (m⁻¹) 换算公式**。原因是 NTU 是 90° 散射的"代理量"，强依赖颗粒粒径/形状/折射率（ISO 7027 规定的就是定量散射法）。文献中 c 与 NTU 的关系总是**站点特定回归**，不可通用外推。
4. 后向散射（backscatter）不是"让图像变暗"，而是**累积成一个随距离饱和的面纱光 B∞**，把远处压成均匀亮场——这直接定义了成像的物理距离上限（[π-SUB, arXiv](https://arxiv.org/html/2608.10589)，B）。
5. 精度影响有 A 级数据：同一网络 AP50 由 **清水 88.2% → 浑浊 79.6% → 深水弱光 75.3%**（[Frontiers Mar. Sci. 2026](https://www.frontiersin.org/journals/marine-science/articles/10.3389/fmars.2026.1859313/full)，A）。

## 一、定量关系

### 1.1 Secchi 盘深度（SDD）与浊度：A 级幂律（USGS 实测回归）

USGS 俄勒冈水科学中心在 Willamette River at Portland（站号 14211720）用 2012-10 至 2014-01 的 **25 对** Secchi 深度／浊度实测数据建立回归（含 1.01 偏差校正因子）：

```
Secchi Depth (ft) = 11.123 × Turbidity(FNU)^(-0.637)
```

来源：[USGS, Estimation of Secchi Depth from Turbidity Data](https://or.water.usgs.gov/will_morrison/secchi_depth_model.html)（**A**）。

换算成公制 `SDD(m) = 3.390 × NTU^(-0.637)`，对应的数据点为：

| 浊度 (NTU/FNU) | 推算 SDD (m) | 推算 SDD (cm) |
|---|---|---|
| 1 | 3.39 | 339 |
| 5 | 1.22 | 122 |
| 10 | 0.78 | 78 |
| 20 | 0.50 | 50 |
| 25 | 0.44 | 44 |
| 50 | 0.28 | 28 |
| 100 | 0.18 | 18 |
| 170 | 0.13 | 13 |

**使用限制（必须声明）**：① 这是**单一河流站点**的回归，换水体（湖泊、养殖塘、近海）系数 k 会变；② SDD 是**垂直方向、目标为高对比白色 Secchi 盘**的可见深度，与"相机水平拍摄某个低对比目标"的距离不是同一个量。我没有找到任何 A 级来源给出"SDD → 相机水平可见距离"的换算系数（例如常见的"水平能见度≈SDD 的 1–2 倍"说法），故**标记为「未找到可靠来源」**。

### 1.2 可见距离的物理控制量是 c 与 Kd（A）

Lee 等人在 *Remote Sensing of Environment* 指出：过去 60 年的 Secchi 深度理论建立在**水下能见度理论**上，而**经典解释强依赖光束衰减系数 c**；他们提出的新机理模型则只依赖**对应最大透明度的漫衰减系数 Kd**。模型用 N=338 组独立实测（涵盖大洋、近岸、湖泊）验证，测得与预测的**平均绝对差约 18%，R² = 0.96**，且适用范围从 SDD < 1 m 到 > 30 m。
来源：[Lee et al., 2015, *Remote Sensing of Environment*](https://doi.org/10.1016/j.rse.2015.08.002)（**A**）。

### 1.3 NTU → 衰减系数 c 的换算：未找到可靠来源

- 检索到的成像物理文献使用的是 `β_b(λ) = a(λ) + b(λ) = c(λ)`（后向散射路径用完整光束衰减系数）、`β_d(λ) = a + δb`（δ=0.05，直射路径），见 [π-SUB (arXiv)](https://arxiv.org/html/2608.10589)（B，预印本）。这些系数是**波长与水体类型相关的 IOP**，论文中不通过 NTU 反演。
- 浊度测量本身由 **ISO 7027-1:2016《水质—浊度测定—第 1 部分：定量方法》** 规定（90° 散射法等），标准定义的是测量方法，并不提供浊度到 c 的换算。[ISO 7027-1:2016 (AFNOR)](https://www.boutique.afnor.org/en-gb/standard/iso-702712016/water-quality-determination-of-turbidity-part-1-quantitative-methods/xs027191/126888)（**A**）
- 结论：**未找到可靠来源给出普适的 NTU ↔ c(m⁻¹) 换算公式**；任何此类换算都必须是特定水体、特定颗粒物的现场标定。

### 1.4 "看得见 / 看不见"的 NTU 阈值：A 级行为学实验

Nieman 等（*Conservation Physiology*, 2018）用视动反应（optomotor response）测定两种鱼能否分辨旋转黑白条纹（条纹宽 3 cm，屏距鱼缸壁 2 cm）：

- 翡翠美洲鱥 *Notropis atherinoides*：失去对比分辨的阈值 **沉积物浊度 79.66 ± 5.51 NTU vs 藻类浊度 34.41 ± 3.19 NTU**（藻类阈值低 43.2%）。
- 大眼狮鲈 *Sander vitreus*：**99.98 ± 5.31 NTU（沉积物）vs 40.35 ± 2.44 NTU（藻类）**（低 40.4%）；混合组 66.10 ± 4.31 NTU。
- 光谱证据：在仅 **20 NTU** 时，沉积物使水下光强降约 **35%**，藻类降约 **42%** 且峰值波长红移约 60 nm（506 → 563 nm）。
来源：[PMC6097597](https://pmc.ncbi.nlm.nih.gov/articles/PMC6097597/)（**A**）。

**解读**：这给出了"生物视觉在厘米级距离上失效"的 NTU 量级——藻类浊度约 **35–40 NTU**、泥沙浊度约 **80–100 NTU**。对相机而言阈值会不同（有增益/长曝光/近红外），但量级可作设计参考。

### 1.5 监管口径上 NTU 与"cm 级可视深度"的对偶（A，PDF 仅见检索摘要）

明尼苏达州污染控制局（MPCA）某流域水质评估文件中并列给出：**浊度标准 25 NTU、总悬浮固体 65 mg/L、透明度管 20 cm**（评估时）。这体现了监管上把"NTU 数值"与"透明度管 cm 读数"作为同一可视性要求的两种表达。
来源：[MPCA 文件](https://www.pca.state.mn.us/sites/default/files/wq-ws5-10230003a.pdf)（**A**；PDF 无法用 web_fetch 打开，此条仅基于检索摘要，**未能核验全文**）。
同类但同样未能读取全文的还有 USGS 的回归报告（把光衰减系数与 TSS、透明度管、浊度、Secchi 深度互建回归）：[USGS LTRMP2010-T001](https://pubs.usgs.gov/mis/LTRMP2010-T001/pdf/ltrmp2010-T001_web.pdf)（**A**，仅检索摘要）。

## 二、后向散射（backscatter）机理与定量影响

### 2.1 Jaffe–McGLamery 模型：两个分量、两种衰减规律

单次散射近似下，相机接收辐亮度分解为**直射（direct）**与**后向散射（backscatter）**两项：

```
I_b = J·exp(−β_d·z)  +  B∞·(1 − exp(−β_b·z))
       └── 直射 D ──┘      └── 后向散射 B ──┘
β_d(λ) = a(λ) + δ·b(λ),  δ = 0.05
β_b(λ) = a(λ) + b(λ) = c(λ)
```

- **直射项指数衰减**（主要由吸收主导，因为水下散射强前向，多数散射光子仍在相机接收角内）；
- **后向散射项沿成像路径累积并渐近饱和到面纱光 B∞**，因此远处区域"收敛到均匀亮场而不是变暗"。
来源：[π-SUB: A Physics-Informed Synthetic Underwater Benchmark (arXiv 2608.10589)](https://arxiv.org/html/2608.10589)（**B**，预印本；其中公式与 Akkaynak & Treibitz 的双系数处理一致）。

同一文献明确指出：**后向散射项在某一距离后饱和，超过该距离场景对比度不再存在，这定义了场景的物理可视范围**（原文："The backscatter term saturates at a range beyond which no scene contrast survives, and this defines the physical extent of the scene"）。

### 2.2 面纱效应侵蚀高频结构（成像模型 → 视觉后果）

水产养殖场景的成像网络论文把 Jaffe–McGLamery 写成 `I_total = I_d·e^(−ηd) + I_fs + I_bs`，并指出：集约化养殖水体中有机物浓度高会**加剧 I_bs**，形成 **veiling effect（面纱效应），侵蚀高频结构细节**；同时红光衰减远快于蓝绿光，造成色偏与语义模糊。
来源：[FinSight-Net (arXiv 2602.19437)](https://arxiv.org/html/2602.19437v1)（**B**，预印本）。

### 2.3 定量的"退化 → 精度"证据（A）

Frontiers 的 DQR-RTDETR 论文把 SeaClear 数据集按图像级退化分数（低对比、模糊、色偏、边缘稀疏四项 z-score 求和）分三档，基线 RT-DETR 的 mAP@0.5:0.95 从**低退化 0.7142 → 中退化 0.7106 → 严重退化 0.6915**（严重档相对下降约 **3.2%**）；而可靠性修复方法带来的 mAP 增益在严重退化档最大（+0.0236，对比低退化档 +0.0134）。这说明**散射/面纱造成的退化越强，检测器越依赖对不可靠候选的抑制**。
来源：[Frontiers in Marine Science, 2026](https://www.frontiersin.org/journals/marine-science/articles/10.3389/fmars.2026.1895210/full)（**A**；XML 全文：`.../1895210/xml`）。

## 四、浑浊水中目标检测/分类精度下降的量化研究

1. **清水 → 浑浊 → 深水弱光（A）**：UW-DualDet（RGB-D 双模态水下检测网络）报告 **AP50 = 88.2%（清水）/ 79.6%（浑浊环境）/ 75.3%（弱光深水）**，整体 mAP 86.7%，推理 116 FPS。
   即"清→浊"绝对下降 **8.6 个百分点**（相对约 **−9.8%**），"浊→弱光"再降 4.3 pt。
   来源：[Frontiers in Marine Science, 2026](https://www.frontiersin.org/journals/marine-science/articles/10.3389/fmars.2026.1859313/full)（**A**）。
   注意：该文按"场景类型"分组，**未给出对应的 NTU 数值**。
2. **退化三档 mAP（A）**：同一数据集按退化分数分组，基线 mAP@0.5:0.95 由 0.7142（低）→ 0.6915（严重），见 2.3（[DQR-RTDETR](https://www.frontiersin.org/journals/marine-science/articles/10.3389/fmars.2026.1895210/full)，A）。
3. **按 NTU 分档的实例分割基准（B，预印本）**：TUB 数据集在水箱中用燕麦奶造出 **10 级浊度**，用浊度计实测后分为 **低 0–10 NTU / 中 10–20 NTU / 高 >20 NTU** 三档，共 1320 张图、16 000+ 实例掩膜；结论是**浊度升高会降低预测能力（即使不存在域偏移）**，而把"极端浑浊图像"加入训练反而会给清晰图像引入歧义、拉低其性能。
   更重要的方法学结论：**感知质量 ≠ 任务可用性**——PSNR/SSIM/UIQM/UCIQE 等指标与下游模型性能弱相关甚至无关，只有他们提出的 PCD（相位一致性）与性能强相关。
   来源：[Beyond Aesthetics: Quantifying Information Loss in Turbid Scenes (arXiv 2606.26295)](https://arxiv.org/html/2606.26295v1)（**B**，预印本）。
4. **受控 NTU/Lux 的鱼类检测基准（B，预印本）**：UW-BlurredFish 数据集在**受控条件下系统改变浊度（NTU）与照度（Lux）**并叠加高斯/运动模糊；FinSight-Net 在该集上达 **92.8% mAP**，比 YOLOv11s 高 4.8% 且参数少 29.0%。该文明确把"浊度引起的散射—后向散射噪点—高频细节丢失"作为检测退化的物理根因。
   来源：[FinSight-Net (arXiv 2602.19437)](https://arxiv.org/html/2602.19437v1)（**B**，预印本）。
   注意：论文报告的是**相对提升**，不是"NTU → mAP"曲线；**未找到可靠来源给出该曲线的显式解析式**。
