## 〇、分类总览（先看结论）

| 公司 | 主要感知技术 | 分类 | 是否计数鱼 | 是否估生物量/体重 | 是否有声学 |
|---|---|---|---|---|---|
| **Umitron** | 网箱内摄像头做**食欲/行为视觉反馈**（FAI）；投饲机自带**料仓称重传感器**；Lens 用**立体相机**测鱼体尺寸；Pulse 用**卫星遥感**（水温/溶氧/海流） | (a) 视觉 + (b) 摄食反馈 + (d) 称重 + 环境 | 否 | 间接（Lens 测个体尺寸，非整箱生物量） | 否 |
| **eFishery** | 水中**振动传感器**读取鱼群摄食运动 → "需求预测" → 定量投料 | (b) 摄食反馈（行为振动） | 否 | 否 | 否 |
| **Aquabyte** | 水下**立体相机 + 计算机视觉/ML** | (a) 视觉（测重 + 计虱） | 部分（个体识别） | **是**（体重分布 + 生物量） | 否 |
| **OptoScale** | 水下**立体相机（3D 成像）+ 高分辨率彩色相机 + 可调 LED**，边缘计算 | (a) 视觉（测重 + 计虱 + 行为/呼吸） | 否（但做重量分布） | **是** | 否 |
| **CageEye** | **水声/回声测深（echo sounder）**，可含多普勒与声学相机 | (c) 声学 + (b) 摄食行为反馈 | 否 | 否（测生物量"位置与分布"，非重量） | **是** |
| **Storvik Aqua / Imenco Aqua** | 投喂相机 + **自动颗粒检测软件**；**"Storvik Frame" 3D 扫描框架**（鱼游过框架测长宽高形状速度）；AquaLog 水质传感器 | (a) 视觉 + (b) 残饵/颗粒检测 + (d) 称重式形体测量 + 环境传感器 | 否 | **是**（框架式 3D 形体测量 → 重量分级） | 否（水产部分） |
| **Aanderaa（Xylem）** | **荧光淬灭式溶氧 Optode** + 海流/温度/盐度/浊度传感器 | (d) 环境传感器 | 否 | 否 | 否 |

**关键结论 3 条：**
1. 真正"靠视觉算生物量"的只有 **Aquabyte** 和 **OptoScale**（外加 Imenco 的框架式 3D 扫描）。
2. **Umitron / eFishery / CageEye 都不做鱼数计数**，它们做的是"摄食反馈"——Umitron、eFishery 靠鱼的行为信号，CageEye 靠声学信号。
3. **没有任何一家厂商的精度声明得到过独立第三方同行评议验证并公布误差数字**；目前最硬的第三方数据来自挪威 FHF 资助、海洋研究所（IMR）与 SINTEF 做的计虱系统验证（仅覆盖计虱，不覆盖投喂量）。

## 一、Umitron（日本 / 新加坡）

### a) 技术分类
**(a) 视觉/计算机视觉（食欲与行为，非计数）** + **(b) 摄食反馈式投喂（视觉反馈，不是残饵颗粒检测）** + **(d) 称重（料仓重量传感器）+ 环境数据（卫星遥感）**。
**不做鱼数计数，不做整箱生物量估计。**

### b) 实际工作原理
官方产品线为 CELL（智能投饲机）、FAI（Fish Appetite Index，食欲指数）、FARM（生产成本管理）、PULSE（卫星海洋数据）、LENS（鱼体测量）、EAGLE（对虾 AI 分析）[1]。

- **UMITRON CELL 的硬件**：可装 400 kg 饲料，含太阳能供电管理系统、机载计算机、**重量传感器**、投料电机，以及一台 **24 小时观察鱼群的摄像头**；远程控制，手机或电脑看视频 [2]。日本政府官方刊物进一步说明：CELL 底部摄像头实时拍摄网箱内鱼群，AI 评估鱼的食欲并优化投料量与投料速度 [3]。
- **UMITRON FAI**：用机器学习与图像分析从视频流中提取数据，量化鱼的食欲并给出评分（绿/黄/红三色"交通灯"提示）；与 CELL 联动可自动调整投喂间隔与数量 [2][6]。其原理是"采用与人类相同的视觉信息给食欲打分"，属于**行为学摄食反馈**，不是颗粒残留检测。
- **UMITRON LENS**：小型**立体相机 + AI**，自动测量网箱内鱼的尺寸并上云；官方承认"使用小体积立体相机导致精度下降"，靠自研算法克服 [5]。
- **专利证据（WIPO，Umitron Pte. Ltd. 共 7 项）**[4]：
  - **WO2018/042651 "FEEDING SYSTEM AND FEEDING METHOD"**（核心专利）：投饲装置 + 摄像头 + 图像处理装置分析图像中的运动；**当图像中的运动量低于预定值时停止投喂**。→ 这是"摄食活跃度"反馈机制，**不涉及计数或生物量**。
  - WO2019/168108：根据饲料**剩余量**自动触发订料。
  - WO2020/017542：用"投喂信息 + 尺寸信息"估算水下生物群的**资产价值**（保险用途）。
  - WO2020/250330：对虾——用摄像头拍摄从养殖塘取出的采集器（collector）来分析虾的信息。
  - WO2021/038753：摄像头检测水生动物 + 满足条件时通知。
  - WO2022/123732：带摄像头的目标仪器 + 供电 + 输出。
  - WO2023/170771：多用户参与投喂的管理装置。

## 二、eFishery（印尼）

### a) 技术分类
**(b) 摄食反馈式投喂（振动/行为传感器）**。
**不是机器学习驱动的鱼数计数，也不是生物量模型。** 公开资料中没有任何证据表明其"需求预测"基于计算机视觉计数。

### b) 实际工作原理（技术细节）
- **核心传感器是"振动传感器"（vibration sensor）**，放置在水中，**捕捉鱼群摄食时的整体运动**，据此分析"饥饿时的运动表现"，从而判定相对饥饿程度 [7]。
- 判定后，**顶装式投料机在预设时间投放定制量的饲料**，并把实时活动数据报告直接发送到养殖户手机 [7]。
- 适用鱼种：鲤鱼、鲶鱼、罗非鱼、南美白对虾；换鱼种前必须重新收集该鱼种的行为研究数据 [7]。
- Aqua-Spark 在投资 eFishery 时将其描述为 "automated **sensor-based** pond feeding system"（基于传感器的池塘投喂系统）[9]。
- **关于"是不是机器学习模型"**：公开可查的描述均为"传感器检测鱼群饥饿行为 → 定量投料"的**信号阈值/行为分析**逻辑，**没有任何公开的技术白皮书、专利或同行评议论文证明其使用深度学习或复杂 ML 模型**。→ 任务中"ML 模型 on 摄食响应/振动传感器数据 vs 实际鱼数计数"的问题，答案是：**是前者（摄食响应型），但连"ML 模型"这一层在公开来源中都无法确证；可以确证的是振动传感器**。

## 三、Aquabyte（挪威 / 美国）

### a) 技术分类
**(a) 视觉计数 / 计算机视觉**——具体是**水下立体相机 + 机器学习**，同时做**体重分布/生物量估计**和**海虱自动计数**。
**是本次调研中唯一明确"用视觉算生物量"且拿到监管豁免的公司。**

### b) 实际工作原理
- 硬件为**水下立体（stereoscopic）相机**，通过计算机视觉与机器学习判断鱼的体型、健康和最优投喂量 [16]。
- 三个产品模块 [13]：
  - **WEIGHT**：每天每箱称重数千条鱼；提供平均体重、生长、K 因子（肥满度）、CV（变异系数），以及**细到 100 g 的体重分级桶（weight buckets）**，用于判断分箱时机与投喂调整 [14]。
  - **LICE**：AI 分析网箱内相机图像自动计虱，**区分成体雌虱、移动期、固着期以及 Caligus（鲺属）**；提供**未来两周的预测**；用户端可看到标注了虱的高清原图 [15]。
  - **WELFARE**：实时福利监测。
- 官网自称运营规模：**每台相机每天 130 万张图像、800+ 套系统在网箱中、8 年数据积累** [13]（厂商自报）。

## 四、OptoScale（挪威）

### a) 技术分类
**(a) 视觉/计算机视觉**——**水下立体相机（3D 成像）+ 专用高分辨率彩色相机 + 可调光 LED，边缘计算（edge computing）**。
同时做**生物量/体重估计**、**海虱计数**、**行为（呼吸频率/游泳速度/倾角）**与**摄食（含颗粒检测）**。

### b) 实际工作原理（重要更正）
- **不是"鱼游过的笼子/通道"**。挪威海洋研究所 2024 年报告对 Bioscope 的现场描述是：**每箱一台相机，按供应商建议放置——置于网箱半径中部（鱼群呈环状聚集处），深度根据鱼群主要游泳深度调整（随季节温度与光照变化）** [27]。
- 硬件构成（官方与 IMR 报告一致）：**水下外壳内装立体相机系统（三维成像）+ 一台专用于虱检测的高分辨率彩色相机 + 两个可调光 LED** [27]。
- **早期技术路线是"结构光"（structured light）**：2018 年 SalmonBusiness 报道称 OptoScale "开发了基于**结构光**的独特技术，比普通相机更容易看清鱼的轮廓和厚度"，并配文"没有相机：来自 BioScope 的视图"（即输出的是 3D 形貌而非照片）[25]。
- **Bioscope 3.0**：一台相机集成多功能；**边缘计算**使数据在相机内处理，不依赖网络覆盖即可持续采集；网络恢复后自动上传；**每天每单元最多 60,000 次获批测量** [23]。
- 官方称其为"plug & play"，可在网箱间灵活移动；提供 API 接入自有分析系统 [22][23]。
- 官方模块：Weight / Lice / Health（伤口、质量分布）/ Behaviour / Feeding（**餐中实时摄食反应 + 颗粒检测**）[22]。

### c) 精度声明
| 数字 | 内容 | 性质 |
|---|---|---|
| **偏差 0.4% 与 0.46%** | 2018 年：与加工厂实测平均体重对比，两个加工厂分别偏差 **0.4%** 与 **0.46%**；当年目标为"平均体重偏差低于 1%" | **厂商自报**（CEO Sven J. Kolstø 接受 SalmonBusiness 采访）[25] |
| **保证 3% 以内** | 2021 年：水下相机每天实时测量，"**guaranteed to be accurate within three per cent**"（保证精度在 3% 以内）；每天可评估多达 **200,000 条鱼**（传统方法约 50–100 条） | **厂商自报**（融资新闻稿转述）[26] |

**第三方验证（唯一有硬数据的项目）——计虱部分：**

## 八、独立的客观综述与第三方对比（本次调研最有价值的部分）

### 8.1 ⭐ FHF 901882 / TELLUS —— 三套自动计虱相机同箱同点对比（SINTEF + 挪威计算中心）
- 报告：**SINTEF Digital 报告 nr. 2024:01541**，2024-12-16，作者 Silius Mortensønn Vandeskog、Solveig Engebretsen、Magne Aldrin（Norsk Regnesentral）、Birger Venås、Mats Mulelid、Leif Magne Sunde（SINTEF Ocean）。FHF 项目 901882《Ytre faktorers påvirkning på bildebasert luseregistrering... (TELLUS)》，预算 336.5 万挪威克朗 [28]。
- 试验设计：**5 个月现场研究，3 套不同厂商的计虱相机安装在同一个场点、同一个网箱、同一时段**；目的是把"位置"这一变量排除，从而量化外部环境因素（能见度、垂直位置、昼夜、水流、波浪）的影响 [28]。
- **主要发现（官方"主要发现"栏）**[28]：
  1. **各系统每日计虱数在趋势和水平上都有巨大差异**；
  2. **各系统每天能拍到鲑鱼照片的数量差异很大**；超过某阈值后，照片数越多并不使计数更可信；且**无法确定有多少是不同个体（同一条鱼可能被重复拍到）**；
  3. **很难对自动计数与人工计数的一致性给出总体评价**，因为自动和人工系统的变异都很大；
  4. **总有一套自动系统比人工计数更早显示上升趋势**——说明自动计数有更早发现变化的潜力；**但三套系统对"何时出现虱量上升"分歧很大**；
  5. **无法用本试验考察的任何变量解释系统间差异**；不同系统在不同深度有明显的昼夜节律，并可能影响计虱结果。
- **FHF 对结果的评估（原文）**："外部因素对用不同相机系统计数有影响。项目已表明，**比较不同的计虱系统是困难的**。所用方法**不适合**就不同环境因素如何影响计数得出结论。同时，结果显示自动计数有潜力比人工计数更早捕捉到趋势变化。" [28]
- **重要限定**：项目组明确说明，为避免"位置"成为额外变量，**未遵循各厂商的用户手册放置建议**（有的系统有自动绞车寻鱼，有的要求主动手动移动到能观察鱼侧面而非网箱中心），此做法已与供应商协商。**因此该结果不代表各系统在最优使用状态下的性能**，但确实展示了不同供应商之间结果差异的潜力 [28]。
- 相关媒体：kyst.no《Slår fast: Store sprik for automatisk lusetelling》（2024-09-26）与《Vil videre med automatisk lusetelling: – Nå får vi fakta på bordet》[28]。

### 8.2 ⭐ FHF 901881 / AutoSOP —— 人工计虱标准化（IMR）
- 见第四节 OptoScale 的第三方数据 [27]。
- 关键方法论发现：**水中计数比空气中计数多检出 5.6 倍固着期虱、1.27 倍移动期虱**；样本量从 10 → 20 → 30 尾时，相对标准误从 22.8% → 16.6% → 13.4%（小规模试验）；麻醉浴中移动期小虱脱落率最高达 29% [27]。
- 监管背景：挪威大约 **1/3 的场点**目前使用自动计虱向当局报告；挪威食品安全局要求厂商提交验证文件才给豁免；2023 年 1 月挪威标准协会（Standard Norge）启动 SN/K 613 标准化项目 [28]。

### 8.3 ⭐ SINTEF Ocean "RACE Autofôring"（AI 精准投喂试点，SINTEF + Spillfree + SalMar）
- 来源：SINTEF 官方博客，2025-05-05，作者 Aya Saad（SINTEF 研究科学家）[46]。
- **饲料成本占总生产成本最高 60%** [46]。
- **系统融合的数据源（这是目前公开资料中对"现代化精准投喂系统"最清晰的技术拆解）**[46]：
  1. **水下视频**（监测鱼的活动与颗粒下沉）；
  2. **生物量传感器**（估计鱼的大小和数量）；
  3. **环境传感器**（溶氧、温度）；
  4. **生产系统**（如 Fishtalk，含鱼的来源、处理、生长历史）。
- 机器学习模型（**含决策树等工具**）处理上述信息以预测最佳投喂策略，并**持续与传统生长模型对比以改进精度**。
- 与旧方案的关键差异：**人工系统是投喂结束后才分析录像，本系统在投喂进行中实时决策**，给操作员即时反馈（增加/减少/停止投喂）[46]。
- 试验设计：在 **Korsneset 的 7 个网箱**中，部分网箱由 ML 建议指导，其余作为对照 [46]。
- **结果表述**："到目前为止结果令人鼓舞。AI 指导的投喂策略显示出改善饲料转化率（FCR）与特定生长率（SGR）的潜力，同时支持更好的福利监测。"——**⚠️ 未给出任何具体数字**，属于"有潜力"的定性表述 [46]。
- 项目还在开发一个新的"**性能评分（performance score）**"以取代人工对"这次投喂是否最优"的判断，目的是让 AI 决策更透明可信任 [46]。

### 8.4 FHF 相关项目与战略投入
- **FHF 901184 LAKSIT**：《Teknologi for nye datatyper og informasjon som beskriver situasjon og tilstand hos laksefisk i kommersielle merder》[49]。
- **FHF 2022-12-12 公告**：投入 **1200 万挪威克朗**用于"新监测技术在养殖业中的技术适配与文档化"，目标是利用已被各类"新"技术平台采集但**尚未被利用的数据与数据关系**，实现福利、盈利与环境改善；这是 LAKSIT 的后续行动 [49]。

### 8.5 行业媒体对"残饵检测"局限性的独立评价
- CageEye CEO 对 AgFunderNews（2018）："**现有颗粒检测技术（测量水箱中漂浮饲料颗粒数量）也不准确。**虽然漂浮颗粒可能说明鱼已吃饱或不饿，但**由于视觉限制或水流，探测器不能总是准确读取水箱中有多少颗粒**。" [9]
- 该评价与 SINTEF/IMR 对"图像法在低能见度下失效"的发现方向一致（高可见度算法在 <6 m 能见度时只检出约 1/5 移动期虱）[27]。
