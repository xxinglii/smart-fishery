# 萤石云：Windows 连接 + 长录像导出 解决方案手册

> 你的情况：Windows 电脑连不上萤石云（未细查）；摄像头在鱼塘现场、插 TF/SD 卡；
> 电脑与摄像头**不在同一网络**（隔着互联网）；目标是**完整导出一段 ≥1 小时的 SD 卡历史录像**（不想被 5 分钟一段地切）。

---

## 一、先分清"连不上"是哪一层（5 分钟诊断）

绝大多数"电脑连不上萤石云"其实是小问题，先按顺序排除：

1. **用手机 App 做基准测试**：手机能看实时/回放吗？
   - 手机也不行 → 账号、摄像头、网络（现场宽带）问题，和电脑无关。
   - 手机可以 → 问题锁定在"这台电脑"。
2. **换网络验证**：电脑开手机热点再连一次。
   - 热点能连 → 是电脑所在宽带/路由器的锅（DNS 污染最常见），可换 DNS（114.114.114.114 / 223.5.5.5）再试。
   - 热点也不行 → 电脑自身问题，继续往下。
3. **检查代理/VPN**：开着科学上网工具时国内云服务经常连不上，先关掉再试。
4. **检查系统时间**：时间不准会导致 HTTPS 证书校验失败（表现为"网络异常"）。让 Windows 自动同步时间。
5. **客户端版本**：到萤石官网（www.ezviz.com）重新下载最新版 PC 客户端（萤石云视频 / 萤石工作室）重装；
   或改走**官方网页版**登录观看（不用装客户端）。
6. 常见问题汇总参考：[萤石云视频PC客户端常见问题汇总](https://www.ruodian360.com/tech/smart-home/47749.html)、
   [萤石云换了路由器APP连不上怎么办](https://www.pconline.com.cn/ask/249482.html)。

> 结论：诊断顺序 = 手机 App 基准 → 换热点 → 关代理 → 校时 → 重装客户端/用网页版。

## 二、安卓模拟器：有用，但别指望它解决导出问题

**结论先行：**
- ✅ 模拟器能当"备用观看通道 + 诊断工具"：如果原生 PC 客户端死活连不上，装个安卓模拟器跑萤石官方 App，App 能正常看 → 说明网络没问题，是客户端问题，直接走网页版或重装即可。
- ❌ 模拟器**不能解除 5 分钟导出限制**——限制在萤石云端/App 层，App 跑在哪都一样。
- ⚠️ 模拟器里的 App 同样走萤石云：如果真是电脑网络连不上萤石云（不是客户端问题），模拟器也一样连不上，白装。

### 怎么查这台电脑有没有装过模拟器
1. 看桌面图标 / 开始菜单里有没有：MuMu（网易）、雷电（LDPlayer）、蓝叠（BlueStacks）、夜神（Nox）、逍遥（MEmu）。
2. 任务管理器（Ctrl+Shift+Esc）进程里搜：`MuMuPlayer` / `LDPlayer` / `Nox` / `BlueStacks` / `MEmu`。
3. 命令行查：
   ```
   tasklist | findstr /i "mumuplayer ldplayer nox bluestacks memuheadless"
   ```
4. 没装的话，Windows 上推荐装 **MuMu 12 或 雷电 9**（国产模拟器对国内 App 兼容最好），官网下载即可，然后装"萤石云视频"官方 App（应用商店里搜）。
   - 常见坑：模拟器默认设置下萤石 App 定位/存储权限要手动开；个别机型 App 在模拟器里画质差，属正常。

## 三、核心问题：远程导出一整段 ≥1 小时录像（绕开 5 分钟限制）

5 分钟/段限制是萤石云端下载的收费墙（参考报道：[萤石摄像头同时下载超4个视频须开通会员？回应：属云端增值服务](https://m.thepaper.cn/detail/29029454)）。
你的录像在 **SD 卡**上，绕开限制有三条路，按推荐顺序：

### 路线 A（0 成本，立刻能用）：回放 + 屏幕录制，整段采集 ⭐推荐先试
原理：不管在哪个终端（Windows 客户端/网页版/模拟器里 App）播放 SD 卡回放，都允许**连续播放**；
限制的只是"导出/下载"，不限制"看着它播"。用录屏软件把播放过程完整录下来即可。

做法（Windows）：
1. 先解决"看得到回放"的问题（第一条诊断清单），在电脑上打开 SD 卡回放、定位到要导出时段的起点。
2. 安装 [OBS Studio](https://obsproject.com/)（免费开源）。
3. OBS 设置建议：
   - 输出 → 录像格式选 **mkv**（防断电丢文件）或 mp4；
   - 关键帧/码率：录的是本地画面，码率设"无损/超高质量"会占空间，设 **1080p + 8~12 Mbps** 足够清晰；
   - 开"自动分段"（按文件大小 4GB 或按时间 1h 分片），避免单个文件过大；
   - 录像时**不要切走播放窗口**：萤石回放一旦切到后台/锁屏，P2P 通道会暂停，录到黑屏。
4. 点"开始录制"→ 点回放"播放"→ 让它播完 1 小时 → 停止录制。
5. 全程不需要人盯：可以先在电脑上放一整夜把要的时段都过一遍（前提是回放支持连续播放——通常支持；注意有的 App 播放到 SD 卡录制缝隙处会自动停，需要手动续播，那就在旁边挂机时多回来点两下）。

手机端同理：手机上全屏回放 + 手机系统自带录屏，但手机不能黑屏/切 App，更适合短段。

### 路线 B（自动化、最优雅）：萤石开放平台 API + ffmpeg 直接拉 SD 卡回放流存盘
原理：萤石开放平台（open.ys7.com，免费注册开发者）提供接口，能拿到"**设备本地录像（SD 卡）回放地址**"（HLS/FLV），用 ffmpeg 拉流落盘——**下载不受 App 5 分钟限制**，想录多久录多久。

步骤概览：
1. 到 [open.ys7.com](https://open.ys7.com) 注册开发者账号 → 创建应用，拿到 **appKey / appSecret**。
2. 添加设备：把摄像头的**序列号（SN）**和**验证码**（机身标签上的 6 位大写字母/数字，或手机 App「设备详情」里可查）绑定到你名下。
3. 获取 token：调接口 `POST /api/lapp/token`（带 appKey/appSecret）→ 拿到 accessToken。
4. 在文档里找到「**获取本地录像回放地址**」（SD 卡回放；云存储的是「获取云录像点播地址」，别混淆）：
   - 文档入口：[开放平台 API 文档](https://open.ys7.com/help/3973)（云录像点播）、
     [文档概述](https://open.ezviz.com/help/1414)（音视频预览/回放），页面里搜"本地录像回放"。
   - 参数一般含：accessToken、deviceSerial（序列号）、channelNo（通道号，单目一般 1）、
     startTime/endTime（要导出的起止时间）。
   - 返回一个带**有效期（通常几分钟）**的 HLS/FLV 地址——拿到后立刻开始拉流。
5. 用 ffmpeg 拉流存盘（Windows 装 ffmpeg 后命令行执行）：
   ```
   ffmpeg -i "拿到.m3u8的完整地址" -c copy -t 7200 上午9点到11点.mp4
   ```
   `-t 7200` = 录 7200 秒（2 小时），可随意调。
   > 提示：先拿 1 分钟地址试拉通，确认能出画面再正式跑长段。
6. 坑与注意：
   - 回放地址会过期，别提前生成地址放那不用；
   - 免费开发者账号能绑定的设备数量有限（够个人用）；
   - 平台界面/接口细节可能改版，菜单找不到就以文档站搜索为准；
   - 合规性：仅用于自己名下设备，没问题。

### 路线 C（一劳永逸，治本）：现场放一台"本地录像机"，以后不靠萤石云
你的核心矛盾是"电脑和摄像头隔着互联网"。如果导出是常态需求（鱼塘要常留档），最省心的长期方案：
在**鱼塘现场**（摄像头同一路由器下）放一台旧电脑 / 树莓派 / 二手 NVR，通过 **RTSP 直连摄像头连续录制**：
- 萤石摄像头在 App 里开启"本地服务/RTSP"（菜单因型号而异，参考：[海康萤石 C6C 摄像头 RTSP 连接方式](https://talk.quwj.com/index.php/topic/3517)、
  [海康萤石摄像头本地局域网拉流保存（CSDN）](https://blog.csdn.net/weixin_48835367/article/details/130967868)），
  记住设备验证码即 RTSP 密码。
- 现场机录完就是本地文件，想拷多长拷多长，完全绕开萤石云和 5 分钟墙：
  ```
  ffmpeg -rtsp_transport tcp -i "rtsp://admin:验证码@摄像头IP:554/h264/ch1/main/av_stream" -c copy -t 86400 今天全天.mp4
  ```
- 需要时再通过网盘/共享/回家拷贝取走文件。

## 四、给你现在的行动建议（按顺序做）

1. **先做第一节诊断**（手机 App 基准 → 换热点 → 关代理 → 校时 → 重装/网页版），把"连不上"修好——这一步不解决，后面都白搭。
2. 连上后，**立刻用路线 A（OBS 录屏回放）**导你需要的那段 ≥1 小时录像，0 成本、今晚就能用。
3. 如果以后经常要导出、且你愿意注册开放平台账号，再上**路线 B（API + ffmpeg）**，全自动。
4. 如果导出是长期高频需求，考虑**路线 C** 在现场部署本地录像，一劳永逸。
5. 模拟器只在你确实想"不修客户端、直接用 App 看"时才有意义（安装 MuMu/雷电 + 萤石云视频 App）。
