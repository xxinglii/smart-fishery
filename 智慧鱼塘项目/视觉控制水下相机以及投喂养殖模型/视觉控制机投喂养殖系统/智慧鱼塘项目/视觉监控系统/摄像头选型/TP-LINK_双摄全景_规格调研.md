# TP-LINK（普联）双摄/双目/全景网络摄像机 — 官方规格核验报告

- 调研日期：2026-09-19
- 数据来源：tp-link.com.cn 官网产品页（规格参数 tab 为主）、TP-LINK 官方商城 tp-linkshop.com.cn（价格）
- 原则：所有数值均来自实际抓取到的页面；页面未写的写“官方未标注”，不做推测
- 重要共性结论（先看）：
  1. **宽动态 WDR（dB）**：本次抓取的 9 个型号的官方规格表中**均无宽动态行**，故全部为“官方未标注”。仅 TL-IPC48DW 卖点写“支持数字宽动态”，无 dB 值。
  2. **GB28181**：9 个型号中**只有 TL-IPC48DW 双摄版的规格表明确列出 GB28181**；其余型号规格表只列 RTSP，未列 ONVIF 或 GB28181（部分型号另有独立行“接口协议：ONVIF”）。
  3. **防护等级**：室内机型（55T2、44AW、43AW、48DW）规格表**均无防护等级行** → 官方未标注；室外机型普遍标 IP66。
  4. **补光距离（米）**：绝大多数型号官方未标注；仅 TL-IPC564VEP-W2.8 卖点写“夜视可达30米”。
  5. **光学变倍**：多数为定焦；变焦仅见于 TL-IPC745 双目变焦版（3倍混合变焦）与 TL-IPC54L4V-WD20（球机三目 20倍混合变焦）。
