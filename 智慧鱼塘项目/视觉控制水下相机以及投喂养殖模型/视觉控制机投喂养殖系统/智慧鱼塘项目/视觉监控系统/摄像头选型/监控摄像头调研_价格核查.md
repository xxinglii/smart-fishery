## 核查方法说明（必读）

1. **京东 / 苏宁 / ZOL / 太平洋 / 立创商城 / 震坤行 / 科力普 / 1688 的商品页价格几乎全部由 JavaScript 异步加载**，本次 `web_fetch` 抓取返回 HTTP 200 但正文为空或无价格字段。因此本次**最稳定可核实的单价来源是政府采购体系**：各省「政府采购网上商城」商品页、以及政采云系「网上超市合同 / 成交公告」（千里马招标网、安防招标网、乙方宝等镜像站），这些页面为服务端渲染，可稳定读出「单价」列。
2. 政府采购成交单价通常**低于**京东自营零售价（工程批量、含税框架价），且同一型号在不同省份成交价差异较大，本表对差异明显者给出区间并在备注中列出全部来源。
3. **证据类型** 三种：`完整抓取`（本次实际抓取到页面正文并读到价格的数字）、`搜索摘要`（价格只出现在搜索结果摘要中，未抓取到页面正文；或来自 PDF 抽取文本）、`未核实`（未能取得价格，标「需询价」）。
4. 本表**未采信**任何占位价（如机电之家部分店铺统一标注的「1.00 元/台」、马可波罗「面议」、得力商城 502 等）。
5. 标注 **【历史价】** 的行为 2024 年之前的价格，仅供趋势参考，不可作为当前报价。
