## 怎么打开

**最简单**：双击 `index.html`（Chrome / Edge / Safari 均可，无需构建、无需服务器）。

**想用本地服务器**（推荐，避免个别浏览器对本地文件的安全限制）：

cd yutang-vision-console
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080

## 这个原型的设计立场

它不是"又一个监控后台"。它把一个**容易被含糊过去的工程判断**摆到界面上：

> **在 50–100 m 的距离上，"看全"和"看清"是互斥的。**
> 所以这套系统是**两台机器分工**：一台定焦广角看全塘，一台 23 倍球机靠巡航看细节。
> 而界面上的每一个数字，都带**证据等级**（A 实测 / B 经验 / C 演示）。

三件通常不会出现在监控 Demo 里的事：

1. **首页第一条就是能力边界的红字**——明确写出"不数鱼、不数颗粒、不估重、不水下观察"，
   因为这四项在本项目调研中已被几何与实测双重否决。**能力边界写在界面上，不是写在说明书第 37 页。**
2. **画面是合成的，而且是有意合成的**。原型里没有真实视频流，所以用 Canvas 合成了一路水面：
   风纹、日光碎斑、投喂时段的抢食水花、夜间红外噪点。**目的是让"水花在这个距离上能不能被看见"当场可判断**，
   而不是靠想象。
3. **事件带置信度与证据等级**。`splash_activity` 用 V-Value（帧差/光流运动占比相对基线的比值），
   标注为 B 级（有文献支撑、本塘未标定）；暗斑聚集标 C 级（演示值）。**未标定的东西不许冒充实测。**

## MOCK 与 LIVE：换后端只改一个开关

- 默认 **MOCK**：全部数据来自 `data.js` 的模拟数据，离线可用。
- **LIVE**：在「设置 → 连接与模式」里填树莓派地址（如 `http://192.168.1.50:8080`），
  点「切到 LIVE」。前端会去调固件的 `/api/v1/*`。

两种模式的数据结构**完全一致**（见 `视觉系统_API契约_v1.md`），
所以"换后端"不需要改任何一行视图代码。

> 联调顺序建议：① 先用 MOCK 看交互；② 树莓派上 `python3 tools/selfcheck.py --simulate` 通过；
> ③ 再切 LIVE 接真机。

## 文件结构

```
yutang-vision-console/
├── index.html      外壳：顶部 tally 条 + 左侧页签 + 主视图 + 底部 24h 事件轴

├── api.js          唯一数据出入口（MOCK / LIVE 双实现 + SSE 订阅）
├── feed.js         合成"实时画面"渲染器（水面 / 水花 / 红外噪点）
├── charts.js       零依赖 Canvas 图表（曲线 / 火花线 / 条形 / 时间轴 / 抓图缩略）
├── app.js          路由 + 8 个视图（纯函数：state → HTML）
└── selftest.js     无头冒烟测试
```

## 自检

```bash
node selftest.js
```

跑 **55 项断言**，两类：

1. **渲染**：8 个视图在完整数据 / 空数据两种情况下都能渲染，且输出不含
   `undefined` / `NaN` / `[object Object]`（模板 bug 的典型症状）。
2. **契约**：模拟数据逐字段比对 `视觉系统_API契约_v1.md`——
   事件类型与严重度枚举、置信度 ∈ [0,1]、时间戳为 Unix 秒、事件按时间倒序、
   RTSP 地址已脱敏、**有且仅有一台相机带云台**、投喂窗口内 V-Value 必须显著高于基线，等等。

## ⚠️ 数据声明

**本原型的全部画面、事件、曲线、设备状态均为演示用模拟数据，不可用于生产决策。**

- 相机型号、镜头参数、红外距离、单价：**真实**（来自本项目选型报告的已核实来源）。
- 画面、事件、读数、日志：**编造**，用于演示交互。
- 真实部署后：画面来自 RTSP，事件来自固件的检测模块，读数为真机读数。

## 技术说明

- 纯静态、零依赖、零构建；图表与画面全部用原生 Canvas 绘制（支持 HiDPI）
- 字体：Chakra Petch（拉丁标题）/ JetBrains Mono（数字）/ Noto Sans SC（正文）；离线自动降级系统字体
- 响应式：≥1180 px 双栏、≥820 px 单栏、<620 px 隐藏次要列
- 实时更新走 SSE；事件到达时只局部重绘（不打断正在播放的画面）
