# 智慧渔业 · 鱼群计数系统

基于传统图像处理（二值化 + 形态学 + 连通域 / 密度估计）的养殖池鱼群自动计数方案，
用于投喂量估算与存塘量盘点：**输入一段航拍视频或一张池面图像，输出鱼群数量的估计值**。

项目包含两条使用路径：

| 路径 | 入口 | 适用场景 |
|------|------|----------|
| **Python 批处理** | `src/count_fish.py` | 整段视频抽帧后批量计数、精度评估、出图表报告 |
| **浏览器端交互工具** | `frontend/index.html` | 单张图像即时调参试算，无需安装环境（纯静态、无后端） |

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt        # opencv-python / numpy / matplotlib
```

### 2. 跑通批处理流程

```bash
# ① 抽帧（数据集已随仓库提供，通常无需重跑；重跑会覆盖 dataset/raw_frames/）
python3 src/extract_frames.py

# ② 计数：遍历 dataset/raw_frames/，输出掩膜、可视化与 output/count_results.json
python3 src/count_fish.py

# ③ 评估：与人工标注对比，输出 output/report.txt 与 output/comparison/evaluation_plots.png
python3 src/evaluate.py

# ④ 展示图：生成 output/comparison/showcase_<视频>.jpg
python3 src/generate_showcase.py
```

### 3. 使用浏览器端工具

```bash
# 方式一：直接双击打开 frontend/index.html
# 方式二：起一个本地静态服务（推荐，避免个别浏览器的 file:// 限制）
python3 -m http.server 8000 --directory frontend
# 然后访问 http://localhost:8000
```

操作流程：上传池面图像 → 选择二值化方法与计数模式 → 按需调参 → 点击「处理图像」
→ 查看「二值化结果 / 检测标记」两张结果图 → 复制或导出计数。

## 算法流程

```
原始帧 → 预处理（CLAHE 增强 / 高斯模糊）→ 二值化（Otsu / 固定阈值）
       → 形态学优化（开运算 + 闭运算）→ 去线（多方向形态学）→ ROI 掩膜 → 计数
```

### 分视频策略（`src/count_fish.py` 的 `VIDEO_CONFIGS`）

| 视频 | 预处理 | 二值化 | 计数方法 | 关键参数 |
|------|--------|--------|----------|----------|
| **351** | CLAHE | 固定阈值 90（反相） | 密度估计 | 单鱼面积 25 px²，去线 |
| **352** | CLAHE | 固定阈值 155 | 连通域计数 | 面积 40–3000 px，ROI 排除上 15% / 右 20% |
| **353** | CLAHE | 固定阈值 95（反相） | 密度估计 | 单鱼面积 20 px²，去线 |
| **882** | 高斯模糊 | Otsu（反相） | 连通域计数 | 面积 15–3000 px，去线 |

### 关键技术

1. **CLAHE 对比度增强**：缓解水面反光、光照不均导致的鱼群对比度低问题；
2. **形态学去线**：用水平 / 垂直 / 对角多方向结构元素提取并剔除绳索等线状干扰；
3. **双策略计数**：个体可分辨时按连通域计数（面积过滤去掉噪声与粘连块），
   鱼群粘连成片时按前景像素总面积 ÷ 单鱼面积做密度估计；
4. **ROI 掩膜**：排除岸边、池壁等非水域区域，避免误检。

### 计数方法怎么选

- **连通域计数**：适合稀疏、个体清晰的场景（如 352、882），结果对面积阈值敏感；
- **密度估计**：适合高密度粘连场景（如 351、353），
  结果 = `前景像素数 ÷ 单鱼估算面积`，**对「单鱼面积」标定最敏感**：
  面积填小了会高估、填大了会低估，需按拍摄高度重新标定。

## 参数说明

### 前端工具（`frontend/index.html`）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 二值化方法 | Otsu 自动阈值 | 光照均匀用 Otsu，明暗差异大用固定阈值 |
| 固定阈值 | 90 | 仅固定阈值模式生效，深色鱼群用反相（低阈值） |
| 反转二值化 | 开 | 深色鱼群（比水暗）需反相；浅色圆斑则关闭 |
| 计数模式 | 密度估计 | 密集粘连选密度估计，个体清晰选连通域 |
| **单鱼估算面积（像素）** | **70** | 密度估计的除数，**一条鱼默认按 70 像素计**；按实际拍摄高度标定 |
| 最小连通域面积 | 20 | 仅连通域模式生效，用于滤除噪点 |

### Python 主程序（`src/count_fish.py`）

参数集中在文件顶部的 `VIDEO_CONFIGS`，按视频号（帧文件名前缀）自动匹配，
键名与上面「分视频策略」表一致；未匹配到的视频走 `VIDEO_CONFIGS['882']` 的配置。

## 性能评估

评估脚本：`python3 src/evaluate.py` → 详细报告见 `output/report.txt`。
（评估集为 11 帧人工标注帧，指标为算法计数与人工计数的偏差。）

### 整体指标

| 指标 | 数值 |
|------|------|
| 评估帧数 | 11 |
| MAE（平均绝对误差） | 27.64 |
| RMSE（均方根误差） | 40.60 |
| MRE（平均相对误差） | 11.08% |

### 分组指标

| 视频 | 评估帧数 | MAE | RMSE | MRE | 全量帧平均计数 |
|------|---------|-----|------|-----|---------------|
| 351 | 2 | 72.5 | 73.3 | 6.3% | 1173 |
| 352 | 3 | 8.0 | 8.0 | 24.9% | 27 |
| 353 | 3 | 39.0 | 48.6 | 7.1% | 1348 |
| **882** | 3 | **6.0** | **6.1** | **4.5%** | 124 |

### 结论

- **882 效果最佳**（MRE 4.5%）：鱼体清晰、背景干净，二值化 + 连通域计数稳定；
- **351 / 353 密度估计有效**（MRE 6–7%）：高密度场景下相对误差可控，但绝对误差较大；
- **352 是主要难点**（MRE 24.9%）：高空拍摄、浅色圆斑对比度低，漏检偏多（系统性低估）。

## 各脚本职责

| 脚本 | 作用 |
|------|------|
| `src/extract_frames.py` | 读取 `videos/`，每 2 秒抽 1 帧写入 `dataset/raw_frames/` |
| `src/count_fish.py` | **核心算法**：单帧处理函数 + 全量批处理入口，输出掩膜/可视化/JSON |
| `src/evaluate.py` | 读取计数结果与 ground truth，计算 MAE/RMSE/MRE 并绘图、写报告 |
| `src/generate_showcase.py` | 拼三合一对比图（原图 / 二值掩膜 / 检测结果） |
| `src/experiments/*` | 调参过程留档：`experiment_binarize.py` 遍历二值化方案，`debug_351/352/352_v2.py` 针对难例调试，`binarize.py` 为早期算法版本（结果写入 `output/debug/`，不覆盖主流程产物） |

## 已知问题与改进方向

1. **参数与拍摄条件强绑定**：阈值、单鱼面积都是针对本项目 4 段视频调的，
   换设备、换高度需要重新标定；
2. **352 类高空浅色鱼群**：固定阈值漏检明显，可尝试顶帽变换（Top-hat）、
   局部自适应阈值或轻量 CNN 分割；
3. **密度估计依赖单鱼面积**：建议先用连通域模式在稀疏帧上统计单鱼平均面积，
   再回填到密度估计参数；
4. **人工标注为近似值**：高密度帧的 ground truth 由抽样密度估算，
   绝对计数指标（MAE）仅供参考，趋势与相对误差（MRE）更可信。

## 归档说明（`archive/`）

- `archive/duplicate_video/`：与 `videos/` 中同名文件 **字节完全相同**（md5 一致）的副本，
  原位于 `鱼群计数/` 目录，为免误删移入归档；
